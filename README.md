# Klipo

키워드로 컷을 고르고, 자막과 더빙까지 붙이는 숏폼 스튜디오입니다. 1분 미만 영상을 올리면 프레임을 읽고 장면 순서를 다시 잡은 뒤, CapCut처럼 타임라인에서 전환을 고를 수 있습니다.

## 할 수 있는 일

- **1분 이하 숏폼 가져오기** — MP4 / MOV / WebM, 여러 클립
- **키워드 컷** — 프레임 샘플 + 장면 감지로 구간을 나누고, 키워드에 맞는 순서로 재배치
- **자동 자막** — 컷마다 한 줄 자막, 클래식 / 박스 / 하이라이트 / 아웃라인 / 미니멀
- **더빙** — 대사 생성 후 보이스 선택, 원본 볼륨과 더빙 볼륨 따로
- **전환 16종** — 컷, 디졸브, 블랙/화이트 페이드, 와이프, 슬라이드, 줌, 아이리스, 블러, 글리치, 스핀
- **미리보기 · 내보내기** — 9:16 릴스 캔버스에 자막과 전환을 합성해 WebM으로 저장

## 사용 흐름

1. 홈에서 영상을 끌어다 놓거나 **샘플로 체험**
2. 키워드를 입력하고 **키워드로 컷 잡기**
3. 타임라인에서 순서를 바꾸고, 컷 사이 `◆`로 전환을 고름
4. 자막을 다듬고 더빙을 입힌 뒤 재생 / 내보내기

데모 클립은 `public/samples/demo.mp4` (12초, 9:16)입니다.
